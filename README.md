# Local Scout holdout 1.8

A frozen, synthetic evaluation set for the local masking in [Local Scout](https://github.com/Angerosteles/local-scout), a privacy plugin for Hermes Agent. It is the source of every quality number for Local Scout 1.8.0 in the plugin's [`docs/EVIDENCE.md`](https://github.com/Angerosteles/local-scout/blob/5f95fb967875e4c17eaa7dc5130e9b489be1d275/docs/EVIDENCE.md).

- **1,503 texts**, frozen on 14 November 2026. Generated by Gemini 4 Hydrogen without access to Local Scout's code. The generator's build scripts (not included) checked span boundaries and searched the unlabelled text for valid card, IBAN, PESEL and SSN numbers and e-mail patterns.
- **9 categories:** `name`, `address`, `phone`, `email`, `card`, `iban`, `pesel`, `ssn`, `secret`. Each has **200 target values** and **50 trap texts** with lookalikes that should stay visible.
- **Languages:** English and Polish, 140/60 values per category (PESEL 60/140, SSN 180/20), plus 60 texts in German, French, Spanish and Italian (15 each).
- **Synthetic only.** No real people are intended. Names, numbers, accounts and secrets are invented; street names can be real streets.
- **Fake keys in real formats.** The `secret` category contains invented API keys and tokens in the formats of real providers (GitHub, AWS, Stripe, Slack, Google, GitLab, OpenAI, Anthropic, npm, Hugging Face, JWT), so that a detector is tested on realistic shapes. None of them is a working credential. Secret scanners will flag them.

The data files are byte-identical to the frozen set, so their Polish file and field names are kept. `docs/EVIDENCE.md` calls the parts `part-a/b/c.jsonl` in its example command; they are the `czesc-a/b/c.jsonl` files here.

```sh
cd data && sha256sum -c SHA256SUMS
```

## Record format

One JSON object per line:

| Field | Meaning |
|---|---|
| `id` | Record ID, e.g. `h18a-name-en-001` |
| `lang` | `EN`, `PL`, `DE`, `FR`, `ES` or `IT` |
| `source` | `synthetic-hydrogen-holdout18:<category>` |
| `kategoria_celu` | Target category of the text; `inne` (= other) for the 60 other-language texts |
| `pulapka` | Trap: `true` for a text with lookalikes and no target value |
| `assessed` | Categories labelled in the text (all 9 in every record) |
| `text` | The text |
| `gold` | `[start, end, category]` spans: Python string offsets, end exclusive, every labelled value of all 9 categories |
| `formy` | `[start, end, form]` for each person name: `full`, `single`, `titled` or `reversed` (see `LABELLING.md`) |

Names occur in many texts besides the name part: 1,311 labelled mentions in total (EN 793, PL 410, other languages 108). EN forms: full 319, single 309, titled 94, reversed 71; PL: 191, 135, 49, 35. 634 texts span several lines; 51 of the 200 addresses are multi-line.

## Reproducing the measurement

The script imports the plugin's local detector and needs its dependencies (`numpy`, `scipy`, `scikit-learn`, `PyYAML`, `threadpoolctl`). Checked with Python 3.14.4, numpy 2.5.4, scipy 1.18.1 and scikit-learn 1.9.1.

```sh
mkdir parent
git clone https://github.com/Angerosteles/local-scout parent/plugin
git -C parent/plugin checkout 5f95fb967875e4c17eaa7dc5130e9b489be1d275    # 1.8.0; c07b215 for 1.7.5
python -m pip install numpy scipy scikit-learn PyYAML threadpoolctl
python -B scripts/holdout_pomiar.py parent data/czesc-a.jsonl data/czesc-b.jsonl data/czesc-c.jsonl \
  --seen data/imiona_widziane_wczesniej.json > my-results.json
cmp my-results.json results/results-1.8.0.json
python scripts/holdout_tabela.py my-results.json default
```

The output reports four settings for 1.8.0: `default` (names `basic`, addresses on, other languages off), `deep`, `other_on` and `deep_other_on`; a 1.7.5 tree is scored once as `v175`. The measurement takes about 8 seconds on a laptop CPU. Both result files in `results/` were reproduced byte for byte from the two commits above.

**What it measures:** the plugin's whole local detection pipeline on each text, with names enabled. A value counts as masked when every letter and digit of its span is covered by detected masks; partly masked when at least one is. A visible false mask is a detected span that overlaps no labelled value. **What it does not measure:** Hermes hooks and request paths, prompt-injection flags, or the optional basal engine.

## Use

The set was measured once, on the first Local Scout 1.8.0 release candidate, without tuning. Two later changes were checked on it and are disclosed in `docs/EVIDENCE.md`: a fix for English titled names and the removal of a small Polish name list. The set is therefore no longer blind for Local Scout. Use a new independent set to evaluate further changes, and do not tune a detector on this one if you want to report its numbers as a blind test.
